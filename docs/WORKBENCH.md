# 工作台定制版

版本：`1.3.0-workbench.3`，versionCode `17`。基于本 Fork 的 corner.3，保留底角手势、原有应用选择和配置，以及先前的输入、动画、拖动与绘制优化。

## 窗口和外观

- 一个主窗加四个独立实时 VirtualDisplay 侧窗。侧窗点击交换、内部拖动、左右布局与任务退出恢复继续使用原来的任务协调器。
- 蓝色系深浅主题、渐变控制面板、圆角侧窗和主窗蓝色边框。主窗圆角由本模块的覆盖层绘制，不覆盖原生任务的圆角状态。
- 左上角固定显示“多任务工作台”和当前日期；右上角依次为比价、支付、More。深浅主题和左右布局切换从 More 打开。常用应用横栏沿用原有选择方式。
- 横向视频／游戏可以占用顶部宽窗，下方保留主窗和另外三个侧窗，总计仍为五个任务。识别依据是应用的横向请求、固定方向，以及已横屏的媒体／游戏任务；不会仅因普通应用随手机旋转就自动置顶。
- “更多 → 横向应用置顶”可手动切换。将宽窗应用切回主窗、关闭或退出横向场景后恢复四侧窗。系统不提供兼容的方向 Hook 时保留原生方向行为。
- 顶部和 More 均无播放器控制；普通布局不保留播放器占位，标题18sp、右上入口48dp。顶部固定142dp（包括状态栏避让、56dp标题行与应用图标行）；旧版保存布局会使用原屏幕与导航标定迁移，主窗和侧窗仍保持应用比例。主窗在可用区域顶部对齐，移除垂直居中产生的上方空隙，不拉伸或裁掉应用内容。

## 付款与比价

右上角“支付”提供微信扫一扫、微信收付款码、支付宝扫一扫和支付宝付款码。优先查询目标应用公开的桌面快捷方式，再使用其已注册的启动入口；不读取账户、密码或付款码，也不自动确认支付。

比价有两个分组：

| 分组 | 目标 |
| --- | --- |
| 外卖 | 京东秒送、淘宝闪购、美团外卖 |
| 购物 | 拼多多、抖音商城、京东、淘宝 |

输入一次商品词，在已安装并支持入口的应用中搜索同一内容。等待虚拟屏创建与任务恢复完成后预留侧窗，只复用同一用户的目标应用或空窗；空窗不够时提示，不覆盖其他任务。准备阶段最多等待约5秒，超时会单独提示小窗未能就绪，不启动后续应用。一个可用目标也可搜索；其他不可用入口在列表中标出。按顺序在主屏启动应用，等待前台任务及其窗口画面就绪后再移入对应侧窗；第一个应用保留在主窗。对话框等待全部落位后才关闭，部分失败显示应用名称、完成数量和原因，区分启动失败与窗口放置失败；取消会停止后续启动。比价指并排查看应用搜索结果，不抓取价格、自动匹配同款、下单或付款。

这些应用内路由属于版本相关的兼容入口。本地检查覆盖输入提交、目标包限制、串行启动与落位、取消和失败恢复、参数编码及窗口预留；没有在当前手机的微信、支付宝或购物应用内实际打开验证。能解析 Intent 不等于已证明该版本会进入预期页面；应用拒绝或调整入口时需从应用内操作，并根据真机反馈适配。

京东即时零售使用其公开前端的 `#/IndexSearch` 路由，淘宝闪购使用 `tb.ele.me/app/eleme/et-search/result` 和 `keyword` 参数；后者的搜索页脚本也用该路径进入结果页。美团使用公开客户端注册的 `/takeout/poi/search`，传入其搜索页读取的 `query` 参数。公开页面与路由的静态核对不代表当前安装版本的真机跳转已通过。

## 添加应用

点击空小窗的“＋”，回到桌面选择应用；下一次桌面应用点击加入该指定小窗。也可点击顶部应用图标完成选择。再次点击同一个“＋”、退出或锁屏会取消选择；目标显示已改变时拒绝回填到错误窗口。

长按顶部应用图标拖入目标小窗，在该窗口打开应用。已有任务优先复用，工作资料或分身的目标用户信息保留。拖入已占用小窗会交换应用，原任务仍保留，原主窗会重新呈现；没有关闭或清除原应用数据。

启动请求被系统接受后，模块会等待实际任务出现，确认任务身份与目标显示后再移动；超时或系统拒绝会给出提示。应用入口和系统窗口能力仍需真机验证。

## 跨应用内容

从主窗应用发起 Android 全局拖动，将文字、图片或文件放到已占用的侧窗，会通过标准 `ACTION_SEND`／`ACTION_SEND_MULTIPLE` 交给目标应用的接收界面。目标应用可能仍要求选择会话或确认操作，不会自动发送给他人。

文件必须是来源授予访问权限的 `content://` URI。模块临时接收拖动权限，启动接收界面后释放；不读取任意本地路径，不执行拖动数据中的 Intent，不以 SystemUI 权限补读未授权文件。目标没有相应接收界面时提示不支持。这不是对所有应用提供任意光标位置的原地粘贴。

微信小程序沿用其真实任务：在系统最近任务中将已打开的小程序卡片置于中央，再点击空窗“＋”加入（沿用原有最近任务选择）。普通微信和独立小程序任务按任务 ID、根组件区分，普通应用入口不会仅按包名抢占小程序。

点击空窗“＋”时，小窗尚未创建、创建失败或存在恢复记录都不会阻止回桌面。选择应用后，先等待目标屏幕就绪并核对任务归属，再启动和放入该小窗；准备失败不覆盖已有任务。已绑定的屏幕被替换时取消旧选择，退出或锁屏会取消待处理启动。

## 显示和隐私

- 小窗使用 secure VirtualDisplay 与 SurfaceView，替代不能承载受保护内容的 TextureView。所有降级候选仍要求 secure，不通过去掉其他应用的 `FLAG_SECURE` 来显示付款页。
- 默认保护工作台截图／录屏。“更多 → 本次允许截图／录屏”只对当前会话生效，退出、锁屏、回桌面／最近任务或打开模块设置时复位，不保存为永久开关。
- 目标应用自身的系统保护、DRM、企业设备策略仍有效。允许截图不保证付款码、密码等内容可以被截取；显示兼容也需真机确认。
- 最近任务隐藏只过滤工作台当前拥有的任务，不删除任务或改写应用的永久最近任务标记；退出／暂停工作台即解除。
- 诊断导出只保存当前 SystemUI 进程内本模块最近128条事件元数据到下载目录，不抓取全量 logcat，不导出搜索词、拖动正文、URI、应用账户或画面。

## 安装和验证

这是预发布版。用户已决定自行真机验证，本轮没有安装到手机、重启手机、操作付款账户或开展真实交易，也没有测量实际帧率、功耗或五应用长期并行稳定性。

可覆盖安装同一 Fork 签名的 corner.1／corner.2／corner.3／workbench.1／workbench.2；本次升级后需重启手机，让 SystemUI、Launcher 和 system_server 同时加载新的运行协议。上游原版签名不同。内置更新仍指向上游，更新为上游包会替换本 Fork 功能。

本地回归包含旧配置迁移、四侧窗／顶部宽窗在竖屏和两种横屏下的布局、控制区边界、主窗与小程序任务区分、搜索词编码和不覆盖其他侧窗、内容授权边界、会话捕获权限复位，以及实际 Android View 的三个顶部入口、日期、无播放器占位、主题、菜单迁移、拖动目标、搜索对话框回调和圆角遮罩，以及加号实际启动 HOME 与取消、旧6/7布局迁移、超时和失败释放输入状态。测试还覆盖未创建／失败小窗的加号、保留恢复任务、迟到的屏幕、取消等待、超时、屏幕被替换及只有一个搜索应用可用的场景。测试依赖只用于本地，不打包进 APK。

完整 Lint 仍有上游遗留的四项错误：`AppCompatCustomView`、两项 `SoonBlockedPrivateApi` 和 `WrongConstant`。构建与测试结果随 Release 的 `verification.json` 提供；不将 Lint 写成全绿。
